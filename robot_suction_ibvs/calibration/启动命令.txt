一、跳过相机标定
保持 [config.yaml](C:/Users/PC/Desktop/shijue/robot_suction_ibvs/config.yaml)：
camera:
  enable_undistort: false
不需要运行：
python calibration/calibrate_camera.py
后续标定和正式运行期间都必须保持 enable_undistort: false，否则程序会认为标定条件发生变化并拒绝旧标定。
同时保证：
相机始终使用同一个设备节点。
实际分辨率始终是 3840×2160。
相机不能重新安装或移动。
相机曝光、焦距、末端姿态尽量保持不变。
二、先设置真实观察位
现在配置里的观察位还是占位值：
observe_pose: [0.0, 0.0, 150.0, 0.0, 0.0, 0.0]
observe_pose_confirmed: false
先通过示教器把机械臂移动到正式观察位置：
相机位于容器正上方。
相机光轴尽量垂直向下。
能看到整个作业区域。
周围至少允许机械臂执行 ±2 mm 的 XY 微动。
Z 和末端姿态以后不再改变。
读取当前末端位姿，填入：
robot:
  observe_pose: [真实X, 真实Y, 真实Z, 真实RX, 真实RY, 真实RZ]
  observe_pose_confirmed: true

  observe_z_mm: 真实Z
注意：
observe_z_mm 应与 observe_pose 的 Z 相同。
标定和运行期间不要切换机械臂工作坐标系。
当前 z_motion_confirmed 可以暂时保持 false，XY 标定不需要下降。
三、标定 servo_A
1. 准备目标
在镜头下面放一个黑色目标，要求：
画面中只能有一个尺寸合格目标。
目标保持静止。
目标不要放在图像边缘。
机械臂移动 ±2 mm 后目标仍然完整可见。
吸管如果遮挡目标，可以暂时拆下，但不能改变相机位置和末端姿态。
先通过 GUI 或检测工具确认只有一个绿色目标：
python tools/inspect_detection.py --config config.yaml
2. 执行标定
关闭 GUI，确保相机没有被其他程序占用，然后运行：
python /home/maic/shijue/robot_suction_ibvs/calibration/calibrate_servo_xy.py \
  --config /home/maic/shijue/robot_suction_ibvs/config.yaml \
  --frames 10 \
  --settle-time-s 2 \
  --sample-timeout-s 20
脚本会自动：
连接相机。
连接睿尔曼机械臂。
移动到观察位。
读取当前工作坐标系。
分别执行这些 XY 微移：
X: -2、-1、+1、+2 mm
Y: -2、-1、+1、+2 mm
每次微移后读取目标像素变化。
每次回到原位置后检查回位误差。
拟合：
像素变化 = servo_A × 机械臂XY位移
执行期间机械臂会自动运动，启动命令前要清空周围空间并准备好实体急停。
3. 成功结果
成功后会生成：
data/servo_A.npy
data/servo_A.npy.json
终端应显示类似：
rank=2
condition=...
fit_rms=...px
Saved data/servo_A.npy and its calibration-context sidecar
默认要求：
目标抖动不超过 3 px。
回位误差不超过 3 px。
拟合 RMS 不超过 2 px。
矩阵秩必须为 2。
条件数不能过大。
不合格时脚本不会保存错误矩阵。
四、标定吸管轴线参考像素
这一步使用 `calibrate_suction_ref.py`。脚本不会移动机械臂；需要先手动将吸管轴线准确放到一个可稳定检测目标的正上方。由于此时镜头仍可看到目标中心，不需要预对准位，也不需要记录任何像素偏移。

保持目标、相机分辨率、观察 Z、末端姿态和工作坐标系不变，然后运行：
python calibration/calibrate_suction_ref.py \
  --config config.yaml \
  --frames 20

窗口显示 `samples=20/20` 且抖动满足限制后，按 A 保存。它生成：
data/suction_ref.npy
data/suction_ref.npy.json

该像素中心就是 `suction_ref_px`：运行时 IBVS 直接把检测到的目标中心移动到此像素；稳定后立即下移吸取，没有额外的终末 XY 或预对准动作。

五、标定完成后应有的文件
最终需要：
data/servo_A.npy
data/servo_A.npy.json
data/suction_ref.npy
data/suction_ref.npy.json
其中 JSON 会记录：
相机分辨率。
是否使用畸变校正。
观察位姿。
机械臂工作坐标系。
标定文件之间的对应关系。
修改相机分辨率、观察位姿、工作坐标系或重新安装相机后，都需要重新标定。
六、首次实机验证
建议先保持：
robot:
  z_motion_confirmed: false
然后启动 GUI，验证：
机械臂到达观察位。
选择正确目标。
IBVS 移动方向正确。
目标中心稳定到达吸管轴线参考像素。
此时吸管位于目标正上方。
程序在准备下降时因为 Z 未确认而停止。
这次测试不会下降，也不会发送 ADP 吸液命令。
确认 XY 完全正确后，再填写真实：
pick_z_mm:
safe_z_mm:
z_down_speed_mm_s:
z_up_speed_mm_s:
z_motion_confirmed: true
首次下降应先把 pick_z_mm 设置在目标上方的安全高度，逐步降低，不能第一次就直接设置到容器底部。
